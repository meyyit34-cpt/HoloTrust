HoloTrust

A decentralized identity and reputation network built with Holochain.

Vision

HoloTrust aims to create a decentralized trust layer for humans, AI agents, and digital services.

Our goal is to enable identity ownership, verifiable attestations, and contextual reputation without relying on centralized identity providers.

Core Principles

* Self-sovereign identity: Users control their own cryptographic identity.
* Privacy by design: Sensitive personal information should not be exposed on public networks.
* Verifiable attestations: Claims should be supported by verifiable evidence.
* Contextual reputation: Trust should be evaluated within a specific context, not reduced to one universal score.
* Agent-centric architecture: Humans, AI agents, and services can participate.

Security

A cryptographic identity proves control of a key. It does not automatically prove a person’s real-world identity.

Never publish passwords, private keys, or sensitive personal information.
